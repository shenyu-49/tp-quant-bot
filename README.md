# 🤖 TP钱包量化交易机器人

**低价买、高价卖、等回调再买** 的网格量化策略，专为 TP钱包浏览器打造。

---

## 📌 策略原理

```
买入 → 涨2% → 卖出 → 等跌1.5% → 再买 → 循环...
```

| 阶段 | 条件 | 操作 |
|------|------|------|
| 首买入 | 无持仓时任意价格 | 买入10%资金 |
| 回调买入 | 价格比上次买入低1.5% | 再买10%资金 |
| 止盈卖出 | 价格比买入价高2% | 全仓卖出 |
| 止损卖出 | 价格比买入价低5% | 全仓卖出 |

## 🚀 快速开始

### 方式1: TP钱包浏览器直接打开
1. 打开TP钱包 → 浏览器
2. 访问部署好的Web地址
3. 点击 **连接TP钱包** 授权
4. 设置参数 → **启动** 机器人

### 方式2: 本地运行
```bash
# 1. 进入目录
cd tp-quant-bot

# 2. 安装依赖
pip install pandas numpy requests flask flask-cors

# 3. 启动后端服务
python server.py

# 4. 浏览器打开 index.html
# 或直接访问 http://localhost:3001
```

### 方式3: 一键启动
```bash
bash run.sh
```

## ⚙️ 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 初始资金 | 1000 USDT | 每次最多投入这么多 |
| 每笔交易比例 | 10% | 每次用资金的10%买入 |
| 止盈比例 | 2% | 涨2%就卖 |
| 买入回调 | 1.5% | 等跌1.5%再买 |
| 止损比例 | 5% | 跌5%强制卖 |
| 检查间隔 | 10秒 | 价格检查频率 |

## 🔒 安全说明

1. **私钥不离前端**：所有交易由TP钱包本地签名，不上传私钥
2. **先用模拟盘**：建议先用小资金测试1-2周
3. **设置止损**：务必设置止损比例，防止暴跌爆仓
4. **定期查看**：不要完全放养，定时检查交易记录

## 📡 API接口

启动服务后访问：
- `GET /` - 首页信息
- `GET /api/prices` - 获取实时价格
- `GET /api/status` - 获取策略状态和信号
- `GET /api/trades` - 获取交易历史
- `GET /api/config` - 获取配置
- `POST /api/config` - 更新配置
- `POST /api/trade/execute` - 手动执行交易
